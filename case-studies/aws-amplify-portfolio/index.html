AWS CLOUD PROJECT · CASE STUDY 01

Deploying a Personal Technology Portfolio with AWS Amplify

A practical cloud deployment project demonstrating how a static website can be hosted on AWS, connected to GitHub, and deployed through an automated build and deployment workflow.

Deployment successful
AWS Amplify Hosting platform
GitHub Source code repository
Europe (Ireland) AWS deployment region

01 / PROJECT OVERVIEW

Project background

I wanted to establish a professional online presence where I could demonstrate my IT support, infrastructure, networking, cloud computing and cybersecurity knowledge.

Instead of stopping at a locally developed website, I took the project further by deploying it to AWS Amplify Hosting and connecting it to a GitHub repository.

02 / ARCHITECTURE

How the deployment works

Developer
Website updates
↓
GitHub Repository
Source code · Main branch
↓
AWS Amplify Hosting
Build and deployment
↓
Live Website
HTTPS · Public access

Workflow: changes are committed to GitHub. Amplify monitors the connected branch and automatically starts a deployment when new commits are pushed.

03 / TECHNOLOGY STACK

Tools and services used

AWS Amplify Hosting

Hosts and delivers the portfolio website.

GitHub

Stores the website source code and tracks changes.

HTML and CSS

Build the website structure and visual presentation.

Visual Studio Code

Used for editing and maintaining the website.

04 / IMPLEMENTATION

What I implemented

  • Created a multi-page personal technology portfolio.
  • Created a GitHub repository for source-code management.
  • Connected the GitHub repository to AWS Amplify.
  • Configured the main branch for deployment.
  • Deployed the website using the Amplify hosting workflow.
  • Verified that the generated public website URL loads successfully.

05 / SECURITY AND OPERATIONS

Security considerations

  • Keep AWS account credentials and access keys out of GitHub.
  • Enable multi-factor authentication on the AWS account.
  • Use HTTPS for public website access.
  • Review AWS account permissions and billing regularly.
  • Monitor deployment status and investigate failed builds.

06 / LEARNING OUTCOMES

What this project demonstrates

This project gave me practical exposure to cloud-based website hosting, source-code management, Git integration, automated deployments and the operational considerations involved in publishing a public-facing application.

Future improvements include custom domain configuration, additional monitoring, performance optimisation and stronger deployment security controls.
